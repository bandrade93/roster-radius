# Security Policy

RosterRadius is designed to process school rosters, so security reports are taken seriously.

## Supported versions

No version has been released yet. Once releases begin, security fixes will be made to the latest release.

## Reporting a vulnerability

**Do not open a public issue for a security problem.** Use GitHub's private vulnerability reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Please include what you found, how to reproduce it, and its possible impact. You will receive an acknowledgement within 5 business days.

## Never share real student data

Do not attach real student or district data to an issue, pull request or vulnerability report. Reproduce problems with synthetic data.
